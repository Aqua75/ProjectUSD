# ProjectUSD Whitepaper

Dieses Verzeichnis enthält das **ProjectUSD Whitepaper** in Markdown-Form.

Die Markdown-Version wird bereitgestellt, damit das Dokument direkt auf GitHub gelesen werden kann und Änderungen im Verlauf der Entwicklung transparent nachvollziehbar bleiben.

Die **offiziellen formatierten Ausgaben** des Whitepapers stehen weiterhin als PDF zur Verfügung und können über die Links auf der Hauptseite des Repositories heruntergeladen werden.

Die Markdown-Version dient daher vor allem:

- der besseren Lesbarkeit direkt im Repository  
- der Versionsnachverfolgung über Git  
- der transparenten Dokumentation der Entwicklung des Protokolls
