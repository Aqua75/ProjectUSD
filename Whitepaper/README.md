# ProjectUSD Whitepaper  
*Central documentation of the conceptual foundation and ongoing development of the ProjectUSD whitepaper*

---

## Overview

This directory serves as the central documentation area for the **ProjectUSD Whitepaper**.

It contains language specific introduction files for this directory as well as the continuously maintained whitepaper versions in Markdown format.

ProjectUSD is an autonomous, oracle independent and self regulating monetary system for PulseChain.

While the **PDF editions of version 2.1** remain available through the main page of the repository, **all later content updates of the whitepaper** will be provided in this directory as Markdown files in **English** and **German**.

This directory therefore fulfills several functions:

- transparent documentation of the whitepaper development  
- direct readability on GitHub  
- traceable version history through GitHub  
- clean referencing of specific document states and revisions  

---

## Contents of this directory

This directory currently contains:

- **README.md** – English introduction to this whitepaper directory  
- **README.de.md** – German introduction to this whitepaper directory  

Updated versions of the whitepaper replace the previous version.  
The directory therefore always contains only the most recent version of each language edition.  
Earlier changes remain traceable through the version history on GitHub.

---

## Role of the whitepaper in the repository

The whitepaper forms the fundamental reference document for the architecture and economic logic of **ProjectUSD**.

Among other topics it describes:

- the system architecture  
- the vault structure  
- the redemption mechanism  
- the stability pool  
- the role of the controller  
- the function of the system rate `r`  
- the economic stability principles of the protocol  

For formal module specifications and detailed technical documentation please refer to **/Architecture/**.

---

## Versioning logic

The **PDF versions** on the main page of the repository document the formatted state of the whitepaper in **version 2.1**.

**Later updates and further development** of the whitepaper will no longer necessarily be maintained as PDF documents, but will primarily be published as **Markdown versions** within this directory.

This directory therefore serves as a continuously updated and publicly visible documentation of the ongoing development of the whitepaper in:

- **German**
- **English**
